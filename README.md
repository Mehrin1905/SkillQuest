A modern and beginner-friendly Hackathon Readiness Portal built using HTML, CSS, and JavaScript.
This project helps students prepare for hackathons through study material, quizzes, and progress tracking.

📌 Features
👤 Student Login System
📊 Interactive Dashboard
📚 Study Material Section
📈 Progress Tracking
🧠 Quiz System with 10 Questions
🏆 Selection Status Based on Score
📱 Responsive Design for Mobile & Desktop
🎨 Modern UI with Purple Gradient Theme
